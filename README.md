# Assignment 4. Forms and Validation

This is my website for assignment 4. It has 5 pages with forms, one page for each task. The navbar at the top is used to go between the pages.

## Pages

- index.html - home page
- task0.html - simple contact form
- task1.html - contact form with HTML5 validation
- task2.html - contact form with Bootstrap
- task3.html - Bootstrap validation (is-valid, is-invalid)
- task4.html - registration form

## How to open

Download the project and open index.html in the browser. Bootstrap is connected with CDN, so internet is needed.
